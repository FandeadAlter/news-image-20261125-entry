A program that draws a newspaper front page summing up the world news of Wednesday 25 November 2026 — the CIA and ODNI hack, Huawei's guilty verdict, Ábrego García's departure for Spain, the WHO evacuation in Congo, the Iowa lead-azide blast, and a record double century — as a 1024×1024 PNG.

Entry for [news-image-20261125](https://make.fun/c/news-image-20261125) ($100). Run with `MAKEFUN_OUTPUT_DIR=out node main.ts` (Node 22, standard library only). The program is deterministic: two runs write identical bytes.
